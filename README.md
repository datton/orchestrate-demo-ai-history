# The History of AI

A static website telling the story of artificial intelligence from its beginnings to today: a timeline, key people, breakthroughs, and where AI stands now.

Built by the Orchestrate Solutions demo team. Plain HTML, CSS and JavaScript, with no build step.

## Pages
- `index.html`: home
- `pages/timeline.html`: timeline
- `pages/people.html`: key people
- `pages/breakthroughs.html`: breakthroughs
- `pages/today.html`: AI today

## Structure
- `css/tokens.css` design tokens, `css/layout.css` layout and navigation, `css/site.css` base styles
- `js/nav.js` navigation, `js/app.js` page behaviour
- `assets/` original SVG illustrations and icons

Open `index.html` in a browser to view it.
